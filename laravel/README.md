# Мейстер — сайт

Сайт транспортной компании «Мейстер»: главная с формой расчёта доставки, список статей, страница статьи и админка статей на Filament (`/admin`).

## Быстрый старт

```bash
make up             # поднять контейнеры
make bash           # зайти в контейнер laravel
php artisan migrate # прогнать миграции
```

Дев-домен: `http://dev.local:8083`.

## Админка

Адрес: `http://dev.local:8083/admin` — откроется форма входа (почта и пароль).

Регистрации в админке нет. Первого администратора создают из консоли:

```bash
make bash                         # зайти в контейнер laravel
php artisan make:filament-user    # спросит имя, почту и пароль
```
